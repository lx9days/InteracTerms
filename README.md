# InteracTerms

Explore 6,388 vocabulary usages from 228 indexed PDFs, 23 ambiguity cases and 37 underspecified expressions. The two case collections preserve their recorded interpretations and limitations. A missing component in a name can still be explained in the paper.

Usages with included PDFs appear first. Open one to read the indexed page immediately, or select **Included PDFs only** to filter the table. The [included papers](pdfs/README.md) retain their original author credits and license notices. Other entries link to the publisher and accept a matching local PDF. Local files stay in the browser for this session. Comparison panels open the recorded source and page for each side. The reader loads precomputed highlights by paper.

Review notes are saved in this browser profile. Export notes downloads a JSON backup. Clearing site storage removes saved notes.

## Build and preview

With Node.js 22, run `npm ci --ignore-scripts` and `npm run build`. Serve the resulting dist directory using a static web server on localhost or HTTPS. GitHub Actions builds and deploys main to GitHub Pages.
